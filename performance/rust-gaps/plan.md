# Rust core gap phase contract

Scope: fill explicitly documented core differences and provide an experimental persistent child-process bridge. No TypeScript runtime changes, no publication, no paid compute. Preserve the earlier frozen benchmark fixtures and results. Initial oracle is the integrated TypeScript built module supplied as an explicit differential argument; record its hash, then repeat against the final TypeScript candidate before performance confirmation.

Correctness comes first: machine-readable spec.json enumerates feature families and explicit rejections. The suite compares complete returned values and mutated ordinary input, retaining own undefined separately from missing and null, including nonfinite and negative-zero values through tagged-v1. Nested assignment results preserve object aliases inside Rust; cross-process serialization returns a tree copy and cannot preserve shared object identity. Cycles, sparse arrays, accessors, host objects/functions, bracket expression reads and unsupported library functions reject explicitly. The CLI retains its original benchmark JSON mode; tagged persistent commands are additional.

Run 12 Rust unit/integration tests, feature cases, 240 generated programs across 12 deterministic expression/control-flow/array/error families, and frozen fixtures. Exercise persistent bridge lifecycle independently: request IDs/framing, concurrent calls, caller cancellation, deadline, process exit/spawn failure, malformed and oversized responses, request/pending/queued-byte limits, close/repeated close and listener/timer cleanup. A timed-out or aborted submitted request kills the owned worker and rejects all outstanding requests, preventing hidden ongoing CPU work. Prepared-program cache is FIFO-bounded to128 syntax-only programs; inputs/results are not inserted into it. Ref-counted values can form cyclic graphs during rule execution, so add explicit rejection of cyclic writes before claiming retention behavior.

Measurement after correctness and candidate freeze: keep the original shared fixtures unchanged for native full comparison. Separately measure persistent prepared-run latency and throughput including tagged encode/pipe/decode, cold process+prepare+first run, unique-program preparation, bounded long-lived cache churn, large-input retention and parent/child memory evidence. Measure real completions and oracle outputs, not declared counts. Record actual Node26/Rust1.99 compiler, source/dependency hashes, request bytes, process blocks and unsupported feature counts. Cold/retention diagnostics do not extend warm throughput claims; compare matched useful work and include bridge overhead. Provisional time bound ~2hours, local cost$0, with at least25% reserved for final confirmation/evidence.

Implementation contract refinement: the session also caps retained program source JSON at1MiB, alongside128 entries. Cyclic writes reject before creating reference-count cycles. Transport uses depth40 rather than the expression/program depth100; these are separate limits. All parenthesized supported functions are listed in the README and will be emitted into coverage JSON. Initial310-case differential run passed, including a caught-and-fixed parser escape mismatch; this is development evidence, not final-source confirmation.
