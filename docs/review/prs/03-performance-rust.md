# Draft PR: Measure hardened TypeScript and tune the Rust core

Status: local review draft; no external PR created. Parent: [Wayfinder](../WAYFINDER.md). Tickets: [03](../tickets/03-performance-rust.md), [05](../tickets/05-residual-contracts.md).

The original library reparsed reused expressions and had no measured Rust integration boundary. Add bounded syntax caching, frozen business-state oracles, completed-work/digest checks, balanced independent process blocks, retained raw observations and paired uncertainty analysis. Compare original source/dependencies, upgrade-only, hardened TypeScript and native Rust. Native array fixtures preserve business results while independent regressions verify corrected internal scope cleanup.

Expand the Rust experiment to structural control flow, arrays, tagged special values and 35 named functions; explicitly reject the other 62 and unsupported transport semantics. Add a bounded prepared-program session and persistent Node child-process bridge with framing, queue/backpressure, cancellation, source-cache and output-expansion controls. Exact float round-trip parsing and bit-based power checks cover numeric boundaries. Rust remains experimental: tree copying, function domains, identity, tracing and isolation differ from TypeScript.

Tune internal array-context checks, then run two additional measured loops: fixed callback save slots/direct indexed reads, and immutable predecoded expression paths. Fresh input reads, captured array length, mutation, nested errors and context restoration have regressions and independent source review. A separate 12-pair before/after experiment confirms the two-loop combination improves native throughput 1.640× [1.590, 1.689]; map-4096 allocation count falls 62.5% and requested allocation bytes 75.5%. Counting allocation instrumentation is excluded from timing.

Final 12-block confirmation on seven unchanged fixtures: hardened TypeScript/original 9.885× [9.737, 10.033], upgrade-only/original 0.993× [0.977, 1.008], and native Rust/hardened TypeScript 10.632× [10.385, 10.898]. The persistent bridge achieves 0.300× [0.288, 0.312] direct TypeScript throughput on those fixtures, about 3.34× slower. Startup and retention diagnostics are separate. Security hardening's separate matched comparison costs about 28% throughput versus the prior tuned TypeScript candidate; no individual guard is assigned that cost.

Validation: 27 Rust tests, 15 bridge tests, 419 shared cases and 11,158 numeric/domain probes pass. Main native confirmation has 336 observations; bridge confirmation has 168. TypeScript passes 462 tests and packed consumers on Node 24 and 26. Retain all valid samples and previous campaigns; cross-campaign variation is larger than the within-campaign intervals.

See [results and decisions](../RESULTS.md), [two-loop evidence](../../../performance/rust-tuning/), and the separate [rules/layers/payload crossover sweep](../../../performance/crossover/README.md). The crossover sweep includes full output-consumption checks and must not be pooled with main-cohort timings. No production SLO, universal crossover, full-language parity or drop-in Rust replacement is claimed.
